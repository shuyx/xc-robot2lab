# D/Q 轴、三相电流与 FOC 原理

## 背景

接续 MIT 五元组讨论，继续深入 FOC 物理原理：D/Q 轴的含义、三相电流的产生机制、弱磁控制的目的。

## 关键分析

### D 轴与 Q 轴的本质

- **D 轴（直轴）**：沿转子永磁体 N 极方向。i_d > 0 → 强化磁阻（更抖但力矩大）；i_d = 0 → 正常模式（最常用）；i_d < 0 → 弱磁（削弱磁场，允许更高转速）
- **Q 轴（交轴）**：垂直于 D 轴的方向。i_q = 真正推动转子旋转的电流分量。τ = 1.5 × p × λ_pm × i_q

FOC 的目标：让合成磁动势向量与转子永磁体始终呈 90° 夹角 → 全部切向力 → i_d = 0 → 最大转矩/电流比。

### 弱磁的原理

高速时反电动势（BEMF = Ke × ω）逼近母线电压 → 电流灌不进去。给负 i_d 对抗永磁体，等效于削弱转子磁场 → BEMF 降低 → 母线电压余量回来 → 可以继续升速。

代价：相同 i_q 产生的扭矩变小（有效磁链 λ_pm 被削）。

### 三相电流的产生

48V 直流电池 → RobStride 驱动板内置的 DRV8353（3 半桥，6 MOSFET）→ SVPWM 合成三相正弦波 → 三组互差 120° 的线圈 → 产生旋转磁场推永磁转子。

逆变器已集成在驱动板中，无需外部配置。

### FOC 完整链路

采样电阻测三相电流 → ADC → GD32 算 Clark/Park 变换 → 调 i_d/i_q → 反 Park → SVPWM → DRV8353 开关 6 个 MOSFET → 三相正弦电流入线圈
