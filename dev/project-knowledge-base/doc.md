## 一、项目背景资料

### 1.1 项目定位与目标

**项目名称**：轮式双臂具身智能机器人的感知与控制关键技术
**项目代号**：XC-Robot（祥承机器人）
**承研单位**：祥承电子（上海）有限公司
**合作单位**：海安智能装备研究院（上海交通大学平台）
**项目类型**：闵行区揭榜挂帅项目 / 技术开发合同
**合同经费**：人民币 45 万元
**项目负责人**：袁鑫

**产品定位**：面向 3C 工厂（SMT 料盘分拣、线边转运、拆码垛）、办公室文件递送、中央仓物流等多场景的**轮式双臂具身智能复合机器人**，目标是以相对克制的成本实现接近人形机器人的感知-决策-操作闭环。

**设计意图**：
- 相比传统 AGV，增加双臂操作能力，完成"移动 + 操作"复合任务
- 相比全尺寸人形机器人，以轮式底盘替代双足，显著降低成本与工程复杂度
- 以**开源 + 国产化**为主基调，掌握从硬件选型到控制算法的全栈能力

**想实现的功能**：
- 自主建图、定位、导航（SLAM + AMCL）
- 双臂协同抓取、搬运、插接、刷墙等操作
- 视觉识别 + 手眼标定 + 抓取位姿估计
- 升降轴自主调节工作面高度（400–500 mm 行程）
- 语音交互、人脸识别
- 电池热插拔 + 自动回充

### 1.2 硬件架构（三层分工）

```
┌─────────────────────────────────────────────────────────┐
│  上层（感知与决策）：X86 Mini PC（Intel i5/i7）          │
│    ├ Ubuntu 22.04 + ROS 2 Humble                         │
│    ├ AI 推理（CPU/iGPU，可选外接加速卡）、视觉识别        │
│    ├ 任务调度、MoveIt 2、双臂笛卡尔规划                   │
│    └ 外设：USB-CAN 适配器 + USB3/GigE 相机 + GbE 交换机    │
├─────────────────────────────────────────────────────────┤
│  下层（实时控制）：X86 Mini PC（Intel i5/i7，可选）      │
│    ├ Ubuntu 22.04 + PREEMPT_RT                           │
│    ├ 底盘导航、IMU 融合、CAN 总线、ros2_control          │
│    └ 轮毂电机 / 激光雷达 / 安全触边 / 急停 IO             │
├─────────────────────────────────────────────────────────┤
│  执行层：关节电机 + 轮毂电机 + 升降伺服 + 末端夹爪         │
│    ├ 双臂：OpenArmX 架构 + 达米奥 DM 电机（见三节）       │
│    ├ 底盘：ZLLG65ASM250 轮毂 + ZLAC8015D CANopen          │
│    ├ 升降：米思米 E-MCH14 丝杆 + 400W EtherCAT 伺服        │
│    └ 末端：智元 OmniPicker 自适应夹爪                     │
└─────────────────────────────────────────────────────────┘
```

> **⚠️ 主控架构重要变更**：**当前实际主控已从 RDK S100 + RDK X5 切换为 X86 Mini PC**（Intel i5 / i7，华硕 Mini PC 或 Intel NUC 等原厂 Mini PC），机器人主控与底盘主控均基于 X86 架构。BOM v2.1 表 A 中的 RDK 方案作为早期规划保留，不再是当前开发的主控基线。详见「三、硬件调整说明」。

**结构模块**：底盘 600×500 mm Q235B 钢板焊接 → 升降轴 500 mm 行程 → 胸部结构 → 双臂（5–7 DOF）+ 头部（RGBD 相机 + 鱼眼 + 麦克风阵列）。

**电源架构**：48V/20Ah 固定电池 + 48V/20Ah 热插拔电池 + UPS 双路切换 + 48V/10A 自动回充；
DC-DC 分三路：主控 48→24V+5V / 执行器 48→24V+24V / 传感 48→12V+5V；升降轴 220V AC 由逆变器提供。

### 1.3 软件架构（ROS 2 Humble 技术栈）

| 层级 | 组件 | 说明 |
|---|---|---|
| **操作系统** | Ubuntu 22.04 LTS + PREEMPT_RT + isolcpus | X86 Mini PC 原生运行，无需交叉编译 |
| **实时控制** | ros2_control + controller_manager | 目标 500 Hz 控制频率，当前 100 Hz，规划升级 |
| **导航栈** | Nav2 + AMCL + Cartographer | 2D SLAM 建图、定位、路径规划 |
| **状态估计** | robot_localization + EKF | 轮式里程计 + IMU 融合 |
| **运动规划** | MoveIt 2 + MoveIt Servo | 双臂笛卡尔 servoing、bimanual_moveit_config |
| **关节控制** | ros2_control + joint_trajectory_controller | 关节轨迹控制 + 阻抗控制（规划中） |
| **通信** | CANopen（底盘）+ MIT 协议（机械臂）+ EtherCAT（升降） | SocketCAN + USB-CAN 适配器（PCAN / ZLG / Kvaser）|
| **视觉** | OpenCV + YOLO（CPU / OpenVINO / 外接加速卡） | 识别、手眼标定、位姿估计；X86 平台可切 OpenVINO / CUDA |
| **语音** | 讯飞 CSK4002 + ASR + TTS + 唤醒 | 远场 6 麦 + 底盘双麦 |

**代码仓库**（ROS 2 包）：
- `openarmx_description` — URDF / SRDF / 碰撞模型
- `openarmx_motor_manager` — CAN 通信、MIT 协议
- `openarmx_ros2` — bringup、hardware、commander、interfaces、bimanual_moveit_config
- `openarmx_teleop_leader` — 遥操作主臂
- `openarmx_tools` — 调参 UI（kp_kd_panel、gripper_panel、teach）
- `chassis_driver` / `chassis_localization` / `chassis_nav` / `docking` — 底盘
- `head_bringup` / `head_voice` / `head_face` / `head_display` — 头部

## 三、硬件调整说明（⚠️ 重点）

> 本章节记录 BOM v2.1（2025-09-24）冻结之后、在实际装机与后续开发中**发生的关键硬件变更**。这些变更**优先级高于 BOM 原表**，是当前项目的实际基线。

### 3.0 主控架构关键选型变更

> **⚠️ 务必准确理解并记忆**：BOM v2.1 表 A 列出的 RDK S100 + RDK X5 主控方案 **已不再是当前的实际主控基线**。

**BOM v2.1 表 A 中规划的主控方案**：
- 上层：**地瓜 RDK S100**（80 TOPS BPU，6 核 A78AE，16 GB LPDDR4X）—— **已弃用**
- 下层：**地瓜 RDK X5**（10 TOPS，8 核 A55，2×CAN / 3×UART）—— **已弃用**
- 扩展板：RDK S100 MCU Port Board + Camera Board（MAX96712）—— **已弃用**

**当前实际采用的主控方案**：

| 项 | 内容 |
|---|---|
| **架构** | **X86_64（x86 / AMD64）** |
| **主控形态** | **Intel Mini PC（小盒子）**，机器人主控与底盘主控均采用同类 X86 Mini PC |
| **候选型号** | 华硕 Mini PC（如 PN 系列、ExpertCenter PN64 等）/ Intel 原厂 NUC（NUC13 Pro / NUC 12 Extreme 等）/ 其他 i5 / i7 级 Mini PC |
| **CPU 档位** | Intel Core **i5 / i7** 12–14 代（10–20 核、性能够用、Mini PC 形态发热可控）|
| **操作系统** | Ubuntu 22.04 LTS + ROS 2 Humble；底盘主控可上 **PREEMPT_RT 实时补丁** |
| **存储** | NVMe SSD（512 GB – 2 TB），DDR4 / DDR5 16–32 GB |
| **接口典型** | USB-A × 4–6、USB-C / Thunderbolt × 2、HDMI / DP × 2、2.5 GbE × 2、M.2 WiFi 6 / BT 5.x |
| **AI 推理** | CPU + 集成 GPU（Intel Arc / iGPU）+ **OpenVINO** 或外接 PCIe / USB 加速卡（如有）|
| **CAN 通信** | **USB-CAN 适配器**（周立功 ZLG / PCAN / Kvaser）或 PCIe CAN 卡，替代 RDK X5 的 2×CAN 原生接口 |
| **相机接入** | **USB 3.0（ROSEB43i）/ GigE Vision**，鱼眼相机考虑改为 USB 方案，**原 MIPI / GMSL + MAX96712 Camera Board 方案弃用** |

**主控变更的原因**：
1. **生态兼容性**：X86 + Ubuntu + ROS 2 是具身智能主流开发环境，完整兼容 MoveIt 2 / Nav2 / OpenVINO / PyTorch / CUDA 等生态，避开 RDK BPU 专用 SDK 的学习与移植成本；
2. **调试便利性**：X86 Mini PC 即插即用，可直连显示器 / 键鼠 / 外设调试，与开发工作站同构，大幅降低工程部署摩擦；
3. **算力灵活性**：Intel i5 / i7 的 10–20 核 CPU 性能充足，配合 iGPU + OpenVINO 即可覆盖感知 / 规划 / 控制的主流负载；必要时可通过 PCIe / USB 4 外接加速卡扩展算力；
4. **工业可靠性**：华硕 / Intel 原厂 Mini PC 具备较好的工业环境稳定性与售后保障，散热与 24/7 运行表现优于消费级开发板；
5. **降低供应链风险**：X86 Mini PC 市场供应充裕，不依赖国产 AI 加速芯片供货周期。

**对软件栈与外设的连带影响**：
- ✅ 完整 ROS 2 Humble 生态原生可用，无需 RDK 定制驱动；
- ✅ MoveIt 2 / Nav2 / robot_localization 等主流包原生可用；
- ✅ CUDA / OpenVINO / ONNX Runtime 推理栈原生可用；
- ⚠️ **CAN 接入方式需改为 USB-CAN 适配器或 PCIe CAN 卡**，替代 RDK X5 原生 CAN；
- ⚠️ **相机接入需从 MIPI / GMSL 改为 USB3.0 / GigE Vision**，MAX96712 Camera Board 不再使用；
- ⚠️ MCU Port Board 功能由独立 MCU 或 ros2_control 硬件接口节点承接；
- ⚠️ 原来规划的 RDK BPU 推理要迁移到 X86 平台（CPU / OpenVINO / 可选加速卡）；
- ⚠️ 功耗 / 散热预算要按 Mini PC 规格重估（典型 45–65W TDP，高于 RDK 模组）。

### 3.1 双臂机械臂关键选型变更

> **⚠️ 务必准确理解并记忆**：当前实际装机方案 **≠** BOM v2.1 文档中列出的两套备选方案。

**BOM v2.1 表 E（双臂）中列出的两套方案**：
- 方案一：**RobStride（灵足时代）** RS04 / RS03 / RS06 / RS02 — **已否决**
- 方案二：**智元 PowerFlow** R86-3 / R86-2 / R52 — **已否决**

**当前实际采用的方案**：

| 项 | 内容 |
|---|---|
| **架构** | **OpenArm 架构的 OpenArmX 版本模组**（开源项目 fork + 二次开发） |
| **电机系统** | **深圳「达米奥」DM 系列电机**（Damiao / 达妙科技） |
| **关键电机型号** | DM-J8009 / DM-J8006 / DM-J4310 等（按肩 / 肘 / 腕层级配置） |
| **减速方案** | 9:1 行星减速器，准直驱（quasi-direct drive）路线 |
| **通信协议** | CAN + MIT 模式（Kp / Kd / 力矩前馈）|
| **自由度** | 7 DOF → 迭代为 5 DOF（实际装机版本）|
| **软件栈** | 自研定制版 openarmx_xc（含 ROS 2 Humble 全套驱动、控制、规划、调参工具） |

**选型变更的原因**：
1. **成本**：RobStride 双臂约 2.0 万元、智元 PowerFlow 约 2.8 万元；**达米奥 DM 电机** 同等扭矩下成本显著更低；
2. **开源生态**：OpenArm / OpenArmX 社区提供完整的 URDF、ros2_control、teleop、dual-arm MoveIt 配置，二次开发效率高；
3. **自主可控**：达米奥电机协议开放（MIT 模式）、配套 SDK 成熟，便于实时控制与自研调参；
4. **技术契合**：9:1 行星减速的准直驱方案与 OpenArm 开源项目的控制算法一致，避免"硬件 - 软件"协议断层；
5. **策略**：BOM v2.1 中保留的 RobStride / 智元方案作为**备选 / 对比参考**，实际装机以 OpenArmX + DM 电机为准。

| 电机方案 | 一体化协作臂（不可拆解）| 分立关节电机（达米奥 DM 系列）|
| 减速 | 谐波减速（FR3 标配）| 9:1 行星减速（准直驱）|
| 成本 | 单臂 > 5 万元 | 双臂 ~1–1.5 万元（电机 + 结构件估算）|
| 可控性 | 黑盒商用 | 白盒开源，全栈自研 |
| 路线定位 | 技术验证 / 客户 demo | 产品化 / 长期迭代 |

## 六、快速对齐要点（每次读本文档必看）

1. **项目性质**：轮式双臂具身智能机器人，合同经费 45 万元，揭榜挂帅项目；
2. **硬件基线**：BOM v2.1（2025-09-24）+ **2 条装机调整**（主控、双臂），以调整后基线为准；
3. **主控方案（⚠️ 已变更）**：**X86 Mini PC（Intel i5/i7）× 2**（机器人主控 + 底盘主控，华硕 Mini PC / Intel NUC 等），**不再使用** RDK S100 + RDK X5；软件栈 Ubuntu 22.04 + ROS 2 Humble；CAN 通过 USB-CAN 适配器接入；
4. **双臂方案（⚠️ 已变更）**：**OpenArmX 架构 + 深圳达米奥 DM 电机**，**不是** RobStride 灵足时代、**不是** 智元 PowerFlow、**不是** 节卡；BOM v2.1 中 RobStride / 智元为备选参考；
5. **当前阶段**：MVP2.0 硬件装配 + 控制调试中，机械臂标定 + 摩擦补偿工程化 + 主控平台迁移为核心任务；
6. **技术路线**：X86 + Ubuntu 22.04 + ROS 2 Humble + ros2_control + MoveIt 2 + CAN/CANopen/EtherCAT；
7. **代际演进**：MVP1.0（FR3 + Hermes + 工控机 商用方案）→ MVP2.0（X86 Mini PC + OpenArmX + DM 电机 自研国产化方案）；
8. **查阅顺序**：先读本文档 → 再按需读 BOM v2.1 解析 / 调试手册 / 代码审查文档。
