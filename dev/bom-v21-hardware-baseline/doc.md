> 1. **A 表 主控**：实际装机**已切换为 X86 Mini PC（Intel i5/i7）× 2**（机器人主控 + 底盘主控，如华硕 Mini PC / Intel NUC），**BOM v2.1 中的 RDK S100 + RDK X5 方案已弃用**，保留作为早期规划参考。

## 汇总与备注

### 1. 与前代 BOM 的主要差异

- **主控**：从单 RDK S100 升级为 S100 + X5 双层脑，新增 MCU Port Board 与 Camera Board（MAX96712）扩展；
- **电源**：固定电池 + 热插拔电池双路方案，配合 UPS 切换模块实现无间断供电；UPS 主板自研化；
- **底盘**：ZLLG65ASM250 轮毂电机 + ZLAC8015D 驱动器方案确定；加入 M10 激光雷达 + CMP10A IMU + ROSEB43i 安全 RGBD；
- **升降轴**：米思米 E-MCH14-L5-500 丝杆模组 + AC 220V 400W 伺服 + EtherCAT 方案确定（需逆变器）；
- **机械臂**：明确保留 RobStride 与智元 PowerFlow 双方案，PowerFlow 方案额定扭矩裕度更大；
- **视觉**：双目 RGBD（ROSEB43i）×2 眼在手上 + MV-EB435i 头部；160° IMX219 鱼眼 ×2 头部补盲；Union image 方案暂放弃。

### 2. 自研 / 定制内容（不计入直接采购）

- 电源管理模块（双路切换、反灌抑制、限流）—— 璟琳智创委托开发
- HVIL 上下身重载快连连接器
- 底盘 Q235B 钢板焊接机架、电机支架、SRC 安装板
- 升降轴底座、上部工装板
- 机械臂 L1/L2 骨架、端盖、外壳、法兰、适配块
