# 弱磁（Field Weakening）机制深析

## 背景

本篇接续 [[05-DQ轴与FOC原理]] 和 [[06-传统vsMIT模式与扭矩生成]]，深入回答一个具体困惑：  
**"给负的 I_d 能削弱转子磁场"——转子的磁场到底怎么来的？负 I_d 如何与之相互作用？**

---

## Q1：PMSM 转子磁场的来源

### 分析

PMSM（永磁同步电机）的转子磁场来自**永磁体（NdFeB 钕铁硼）**，产生恒定磁链 ψ_f。

关键事实：**永磁体的磁场是固定的，无法被定子电流消除**。  
"弱磁"这个名字有误导性——你弱掉的不是永磁体本身的磁场，而是**定子回路感受到的总磁链 ψ_total**。

### 结论

转子磁场来源 = 永磁体，恒定不变。负 I_d 只能改变叠加后的等效总磁链，无法改变永磁体本身。

---

## Q2：负 I_d 如何"削弱"磁场（弱磁的物理机制）

### 分析

FOC 里的 D 轴（直轴）方向定义为**与转子永磁体磁通方向平行**，Q 轴垂直于 D 轴。

**总磁链公式**：

```text
ψ_total = ψ_f + L_d × I_d
```

- `ψ_f` = 永磁体磁链（固定常数，不可改）
- `L_d`  = D 轴电感
- `I_d`  = D 轴电流（正常运行时 = 0，弱磁时 < 0）

**反电动势**：

```text
E_back = ω × ψ_total
```

高速时的问题：

```text
E_back → V_bus（母线电压）
→ 电压裕度 = V_bus - E_back → 0
→ 无法继续灌入 I_q
→ 转矩崩塌
```

弱磁的解法：令 `I_d < 0`，定子 D 轴绕组产生一个**与永磁体磁通方向相反的磁场**，两者在磁路中叠加后：

```text
ψ_total = ψ_f + L_d × I_d（I_d < 0）
→ ψ_total < ψ_f
→ E_back = ω × ψ_total 降低
→ 电压裕度恢复
→ I_q 可以继续灌入
→ 维持转矩
```

### 架构 / 流程图

```mermaid
flowchart LR
    A["转速 ω 升高"] --> B["E_back = ω × ψ_f\n逼近 V_bus"]
    B --> C["电压裕度不足\nI_q 灌不进去·转矩崩塌"]
    C --> D["注入负 I_d"]
    D --> E["ψ_total = ψ_f + Ld × Id\n总磁链降低"]
    E --> F["E_back 降低\n电压裕度恢复"]
    F --> G["I_q 维持\n转矩得以延续"]
```

### 物理直觉类比

永磁体 = 一块强度固定的磁铁。  
D 轴定子绕组 = 旁边一块**可反向的电磁铁**。

弱磁时，把这块电磁铁反向通电，两者磁场在气隙磁路里**部分抵消**——永磁体本身没变，但整个磁路中流通的磁通量减少了，感应出的反电动势降低。

### 结论

弱磁 = 用负 I_d 在 D 轴方向制造反向定子磁场，抵消部分永磁体磁链，降低 E_back，换取高速端的电压裕度，代价是有效磁链降低导致相同 I_q 下转矩减小。

## Q3：对 XC-Robot / Robstride 关节的实际影响

### 分析

Robstride RS03/RS04 的弱磁由驱动器内部 FOC 自动处理，MIT 层感知不到。但在以下场景会出现明显效果：

| 场景 | 现象 | 原因 |
|------|------|------|
| 大臂快速甩出（高速段）| 关节输出转矩下降 | 进入弱磁区，I_q 受压 |
| 高速运动突然加大负载 | 速度崩落而非顺滑减速 | 弱磁储备不足 |
| MIT 模式 Kd 过大 | 高速端阻尼力矩失真 | 速度前馈值推进弱磁区边界 |

Robstride 的力矩-速度曲线**不是线性的**，在额定转速附近开始折弯，折弯点即弱磁区起始位置。调参时高速端的 Kd 效果会比低速端弱，需留意。

### 结论

弱磁是驱动器自动行为，MIT 调参时需意识到：高速端五元组设定的力矩前馈 / Kd 阻尼实际输出能力受弱磁区影响，调参数据需在目标速度范围内验证。
