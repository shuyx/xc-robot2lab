## 技术背景

- **当前状态**：ROS2 离散轨迹，纯调参，缺底层运动规划；轨迹无时间轴
- **目标**：类 JAKA/Aubo/UR 的 C++ 底层运动规划系统；轨迹数据自动解算角速度 → 平滑输出
- **依赖**：
  - `02-关节抖动根源解析/` — 硬件约束已知，规划层才有设计依据
  - `03-重力补偿前馈/` — 补偿稳定后，规划层平滑才有意义

## 核心问题

| 问题 | 说明 |
|------|------|
| 关节空间 vs 笛卡尔空间规划 | 各自适用场景与切换逻辑 |
| MoveIt Servo 模式 | 是否启用，与当前架构兼容性 |
| 时间参数化 | 给裸轨迹加时间轴（速度/加速度约束） |
| 在线规划 vs 离线规划 | 实时性要求与 openarmx_xc 架构匹配 |
